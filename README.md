# NDVM 통합 프로젝트 (UI + Leaflet 지도 + 안전동행 5대 기능 + FastAPI 백엔드)

## 개요
NDVM(Natural Disaster Vulnerability Map)은 공공데이터를 기반으로 한 **자연재해 취약지역 분석 대시보드**와 시민 참여형 **안전동행 5대 재난 대비 도구**, 그리고 **FastAPI 백엔드**를 하나로 통합한 웹 애플리케이션입니다.

## 주요 구성
- `frontend/`: 통합 웹 프론트엔드 (정적 웹 / PWA 오프라인 캐시 지원)
  - **7대 재해 분석 & 전국 251개 시·군·구 취약도 지도**: 침수·홍수, 산사태, 태풍, 폭염, 폭설, 가뭄, 지진 일체형 대시보드
  - **실시간 긴급재난문자 티커 & 지도 레이더 펄스(Pulse)**: 상단 속보 전광판 및 지도 위 2중 파동 애니메이션
  - **안전동행 5대 재난 대비 도구**:
    1. **위험요소 신고서 작성기**: 종류/장소/날짜/설명/선택 사진 입력, 지도 선택 지역 자동 연동, 문서 미리보기, 텍스트 복사·저장, 인쇄/PDF
    2. **비상 연락 카드 생성기**: 비상 연락망/가족 집결지 입력, Canvas 기반 PNG 다운로드 및 인쇄
    3. **구호물자 매칭 시연**: 지역/품목/수량 기준 가상 요청·지원 목록 일치 검색
    4. **비상용품 스마트 관리함**: 이름/분류/수량/유통기한 등록, 수량 +/− 조절, 부족·임박 필터링, TXT 보충목록 저장, 전체 물품 CSV 내보내기, 로컬 영구 보관
    5. **안심 그룹 오프라인 릴레이**: 그룹 코드/안부 메시지/대략 위치 기록, 오프라인 QR 코드 생성(내장 엔진), 카메라 QR 스캔, 전달 코드/TXT 파일 교환, 최대 4단계 홉 제어 및 중복 방지
  - **대피시설 조회 & 단계별 재난 행동요령**: 전국 지진옥외대피소, 민방위 대피소, 무더위쉼터 검색 및 행안부 국민안전포털 표준 행동수칙 통합
  - **기상청 ASOS 관측 강수량 조회** 및 **과거 자연재난 피해 통계 시각화**
- `backend/`: FastAPI 백엔드 (기상청 ASOS 일자료, 한강홍수통제소 WMS 설정, 실시간 재난문자 API 등)
- `run_ndvm.py` & `시작하기.bat`: 별도 패키지 설치 없이 Python 표준 라이브러리만으로 1클릭 실행 가능한 로컬 서버 러너

## 빠른 실행 방법 (Windows)

### 방법 A. 1클릭 시작하기 (추천)
1. 프로젝트 루트의 `시작하기.bat`을 더블클릭합니다.
2. 자동으로 로컬 웹 서버가 실행되며 브라우저에서 `http://127.0.0.1:8765/#action` (또는 `#home`) 주소로 열립니다.

### 방법 B. VS Code Live Server 또는 Python 명령어
```powershell
cd frontend
python -m http.server 5500
```
브라우저에서 `http://127.0.0.1:5500`으로 접속합니다.

---

## 백엔드 실행 (선택: 기상청 API 및 실시간 연동)

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m uvicorn app.main:app --reload --port 8000
```
- 백엔드 주소: `http://127.0.0.1:8000`
- API Swagger 문서: `http://127.0.0.1:8000/docs`
- 백엔드가 실행되지 않아도 프론트엔드는 내장된 데이터베이스와 오프라인 폴백 모드로 100% 정상 작동합니다.

## 중요 안내
- 현재는 대한민국 전체의 기본 지도와 지역 대표 위치 표식을 표시합니다. 행정구역 경계 색칠은 다음 단계에서 경계 GeoJSON을 연결해야 구현됩니다.
- 위험도는 과거 피해 기록을 이용한 시범 점수입니다. 실제 침수 확률이나 정부의 공식 위험등급이 아닙니다.
- OpenStreetMap 공개 타일은 사용 정책을 준수해야 합니다. 이용량이 많거나 상용 배포 시에는 별도 타일 제공자의 약관/요금제를 확인하세요.
- 프론트엔드 Leaflet 파일은 CDN에서 로드되므로 인터넷 연결이 필요합니다.


## 행정구역 경계 지도 (1단계)

- 지역별 취약도 지도 페이지에서 시·군·구 경계 GeoJSON을 불러와 표시합니다.
- 경계에 마우스를 올리면 지역명이 표시되고, 클릭하면 해당 구역이 강조됩니다.
- 경계 데이터 출처: `DevMinGeonPark/mapcn-kr` 저장소의 SGIS 기반 시·군·구 데이터.
- 브라우저에서 외부 GeoJSON을 가져오므로 인터넷 연결이 필요합니다.
- 이번 단계에서는 경계 클릭/강조까지만 구현했습니다. 기존 지역 점수 데이터와 경계 속성의 정확한 매칭을 검증하기 전에는 점수 색칠을 하지 않습니다.


## 확장 기능 (2026-11)
- **우리 동네 재난 정보 한눈에 보기 (신규)**:
  - 전국 251개 시·군·구 중 원하는 지역을 지도나 목록에서 클릭하면 한 화면에서 원스톱으로 확인:
    1. **현재 강수량**: 실시간 강수량(mm/h), 1시간/24시간 누적량, 기상청 ASOS 관측소 명칭
    2. **과거 침수 이력**: 침수 횟수, 주요 피해 연도, 대표 수해 사례 및 최대 침수심
    3. **주변 대피소**: 지진옥외대피장소, 민방위 대피시설, 무더위쉼터, 수용인원 및 원클릭 길찾기
    4. **가까운 병원**: 24시간 응급실 가동 상급종합병원, 지역응급의료센터, 보건소 연락처
    5. **침수 취약시설**: 저지대 지하차도(진입차단기 가동 여부), 반지하 주택 밀집지, 배수펌프장
    6. **현재 재난 경보**: 지역에 발효된 긴급재난문자·특보 및 맞춤형 행동수칙
- **실시간 인구 밀집도 & 유동인구 기반 '동적 취약성(Dynamic Vulnerability)' 분석 (신규)**:
  - 고정된 건물·인구 센서스를 넘어 시간대별(0~23시)·요일별(평일/주말) 실시간 유동인구 가중치 결합
  - 출퇴근 시간(08~09시, 18~20시) 강남, 여의도, 서면 등 인파 과밀 시간대에 폭우·침수가 결합할 때 동적 위험도가 어떻게 치솟는지 24시간 시뮬레이션
  - **타임라인 컨트롤러**: 24시간 슬라이더, 원클릭 프리셋(심야, 출근, 주간, 퇴근피크, 야간), ▶ 24시간 자동 애니메이션 재생
  - **지도 시각화**: 전국 251개 지자체 경계 색상이 시간대별 동적 위험도에 따라 실시간 전환 + 전국 주요 거점 15개소 '유동인구 파동 펄스 버블' 오버레이
- **지도창 자동 맞춤 (Auto-fit to Viewport)**:
  - 지도 화면이 대한민국 전역(마라도~휴전선, 서해 도서~울릉도/독도)을 지도창 크기에 완벽히 맞춰 자동 조정 (`fitBounds`, `zoomSnap: 0.25`, 리사이즈 반응형)
  - 지도 상단 `대한민국 전체 ⟲` 버튼으로 언제든 전국 뷰로 리셋 가능
- **재해 유형별 분석 & 취약도 지도 완전 통합**:
  - 기존에 분리되어 있던 '재해 유형별 분석'과 '지역별 취약도 지도'를 하나의 일체형 대시보드로 통합
  - 상단 7대 재해 칩(`침수·홍수`, `산사태`, `태풍`, `폭염`, `폭설`, `가뭄`, `지진`) 클릭 시 분석 개요/3대 핵심 지표와 전국 251개 시군구 지도 취약도 색상이 실시간 동기화
  - 공간 활용을 위한 분석 요인 접기/펼치기(Accordion) 기능 지원
- **실시간 긴급재난문자 티커 & 지도 레이더 펄스(Pulse) 효과**:
  - 상단 헤더 아래 실시간 재난문자 방송 전광판 (자동 롤링, 이전/다음, 일시정지, 보관함 모달)
  - 티커 클릭 시 지도 내 해당 재난 발생 구역으로 부드러운 카메라 이동(`flyTo`) 및 상세 팝업 오픈
  - Leaflet 지도 위 2중 파동 레이더 펄스(Pulse) 애니메이션 마커 오버레이 (`🚨 재난문자 레이더` 토글)
  - 팝업 내 해당 지역 대피시설 원클릭 바로가기 연동
- 지역명 검색 보조와 선택된 지역 상세 패널 유지
- 브라우저 위치 권한을 사용한 지도 내 현재 위치 표시 (사용자 동작 시에만 실행)
- `/api/statistics/flood`에 연결된 과거 피해 통계 그래프 및 상위 지역 목록
- `/api/shelters`의 실제 연결 상태 표시. 데이터가 미연결이면 임의의 대피시설 정보를 생성하지 않고 미연결 상태를 안내
- `/api/disaster-alerts`: 전국 실시간 긴급재난문자 발령 API 및 백엔드 미실행 시 오프라인 자동 폴백
- 모바일 반응형 스타일 보강

## API 연결 상태 안내
- `/api/health`: 기상청 키, WMS 설정 여부를 확인합니다.
- `/api/weather/daily-rain`: 기상청 ASOS 일자료를 조회합니다.
- `/api/flood/map-config`: 설정된 하천범람 WMS 레이어 설정을 프런트엔드에 전달합니다.
- `/api/flood/history`, `/api/flood/risk`, `/api/flood/risk/all`, `/api/statistics/flood`: 과거 침수 CSV를 읽는 레거시 엔드포인트입니다. CSV가 없으면 503을 반환하며, 현재 자동으로 공식 API 데이터를 대체하지 않습니다.
- `/api/shelters`: 아직 실제 대피시설 API가 연결되지 않은 상태를 명시적으로 반환합니다.

하천범람지도는 시나리오 기반 범람 지도이며, 실시간 침수 관측이나 과거 피해 기록과는 다릅니다. 공식 데이터 출처와 이용 조건을 확인하세요.


## 지도 확대 및 기상청 API 연결
- 지도 높이를 데스크톱 최대 820px / 화면 높이 기준 76vh로 확대하고, 화면이 좁으면 지도 아래에 상세정보 패널을 배치합니다.
- 지도 아래에 기상청 ASOS 일자료 조회 패널을 추가했습니다. 관측소와 날짜 범위를 지정해 일별 강수량 및 평균기온을 조회합니다.
- 실제 API 호출에는 공공데이터포털에서 발급한 기상청 인증키가 필요합니다.

### 기상청 API 설정
1. 공공데이터포털에서 **기상청 ASOS 일자료 조회서비스** 활용 신청 후 인증키를 발급받습니다.
2. `backend/.env.example`을 복사해 `backend/.env`로 저장합니다.
3. `KMA_SERVICE_KEY=` 뒤에 발급받은 인증키를 입력합니다. 인증키는 프런트엔드 코드에 넣지 마세요.
4. 백엔드 폴더에서 `pip install -r requirements.txt`를 실행합니다.
5. `uvicorn app.main:app --reload --port 8000`으로 백엔드를 실행합니다.
6. 별도 터미널에서 `frontend` 폴더로 이동해 `python -m http.server 5500`을 실행합니다.
7. 브라우저에서 `http://localhost:5500`을 엽니다. 지도 페이지에서 관측소/기간을 고르고 **강수량 조회**를 누릅니다.

API 키가 설정되지 않았거나 기상청 API 권한이 승인되지 않은 경우, 오류 상태가 화면에 표시됩니다. 관측 자료는 과거 일자료이며 실시간 재난 경보가 아닙니다. 지도상의 원형 표식도 행정구역 경계 자체를 칠하는 것은 아닙니다.


## API-only 업데이트 참고
`backend/.env`는 개인 인증키가 들어갈 수 있어 ZIP에서 제외했습니다. `backend/.env.example`을 복사하여 본인 인증키를 설정하세요. ZIP에는 인증키를 포함하지 마세요.
